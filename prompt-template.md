# On-Page SEO Evaluation Template

Use this template with approved content only. Replace the bracketed fields with non-confidential material.

## Evaluation criteria
Review the draft for:
1. Alignment with the stated search intent
2. Clear, accurate, and useful information
3. First-hand experience, expertise, authority, and trust signals
4. Heading structure and topical coverage
5. Opportunities for internal links, examples, and concise explanations

Return:
- strengths

- questions_for_editor

Do not invent facts, citations, or performance claims.
