# Claude AI On-Page SEO Automation

A sanitized showcase of Claude AI-assisted workflows for content evaluation and on-page SEO operations.

## What it demonstrates
- Turning an SEO brief into a structured evaluation request
- Checking content against search intent, helpfulness, and EEAT signals
- Returning consistent JSON for review and reporting
- Keeping editorial judgement in the loop instead of automating publishing

## Evaluation flow
~~~text
SEO brief + draft content → Claude evaluation → Structured scorecard → Human review → Recommendations
~~~

## Included
- prompt-template.md: a reusable, provider-neutral evaluation template
- A framework for building an EEAT-style scorecard

## Portfolio note
This repository is a public, sanitized demonstration. It contains no company content, private prompts, API keys, or internal implementation details.
